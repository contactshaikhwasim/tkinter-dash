Roadmap
=======

The roadmap is evidence-driven. A feature should be justified by a concrete use case and supported by regression coverage.

Near term
---------

* Better axis tick generation and label density.
* More robust dynamic margins for large numeric values.
* Stronger type annotations and API documentation.
* Larger real-world regression datasets.
* Benchmarking for dense rendering and interaction.

Medium term
-----------

* Adaptive, viewport-aware downsampling for dense line charts.
* Datetime-aware x-axis support.
* Crosshair interaction.
* A dedicated streaming API.
* A true XY scatter model.
* Smoother data-to-data transitions.

Longer term
-----------

* Zoom and pan.
* Linked or cross-filtered charts.
* KPI, gauge, sparkline and other dashboard widgets.
* Migration guidance/tools for common Tkinter + Matplotlib projects.
* Optional Pandas/NumPy adapters.

How to influence the roadmap
----------------------------

The best contribution is a narrowly scoped improvement supported by:

* a reproducible use case;
* a focused API proposal;
* regression tests;
* documentation;
* evidence that the new behavior is useful on real data.
