Tkinter-dash
============

**Modern, interactive dashboard and visualization widgets for Tkinter.**

``tkinter-dash`` is a lightweight Canvas-based visualization library for Python desktop applications. It provides reusable charts with animation, hover interaction, tooltips, themes and responsive resizing while staying inside the Tkinter widget model.
